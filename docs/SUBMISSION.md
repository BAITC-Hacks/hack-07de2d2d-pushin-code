```
Windcast — Agentic AI-система прогноза почасовой выработки ВЭС из двух турбин на 48 часов. Агент сам получает по координатам архивный прогноз погоды Open-Meteo, опубликованный до момента выпуска, проверяет данные, запускает квантильную модель (P10/P50/P90 по турбинам и ВЭС), анализирует риски и пересчитывает при новом прогоне. Февраль 2026 воспроизведён как в прошлом: 29 выпусков, правило «без будущего» проверяет verify.py. Январь: nMAE 15,8 % против 19,4 % у лучшей базовой линии.
```

## Описание, 1500 знаков

```
Windcast — Agentic AI-система для диспетчера ветроэлектростанции из двух турбин (43.645, 78.536). Диспетчер каждый день заявляет почасовой график на сутки вперёд, а отклонение факта от графика — небаланс, который покрывают резервом и за который платят. Windcast к каждому моменту выпуска сам получает по координатам ВЭС архивный прогноз погоды из Open-Meteo Previous Runs API, беря только прогоны, опубликованные до этого момента (правило init + 8 ч ≤ T), проверяет данные, запускает квантильную модель (scikit-learn, P10/P50/P90) и выдаёт прогноз на 48 часов для каждой турбины и ВЭС. Затем агент анализирует результат (рампы, обледенение, ветер > 20 м/с), при выходе нового прогона сам решает, нужен ли пересчёт, и публикует выпуск: CSV, сводку для диспетчера и ленту своих шагов. Порядок шагов и решения — за LLM (gpt-5.4-mini, function calling), числа считает только модель; без ключа тот же цикл идёт по правилам и даёт те же числа. Февраль 2026 воспроизведён день за днём: 29 выпусков с 31.01 по 28.02, все с пересчётом v2 по решению LLM; правило «без будущего» проверяет независимый scripts/verify.py (14 проверок, PASS). На январском бэктесте nMAE 15,8 % номинала против 19,4 % у кривой мощности, 26,8 % у климатологии и 36,5 % у персистентности; покрытие P10–P90 — 80,5 %. В режиме Live агент сам раз в 30 минут проверяет новые прогоны и ведёт журнал. Демо без регистрации: https://pushin.codes. Запуск: git clone, docker compose up --build, python3 scripts/verify.py.
```
