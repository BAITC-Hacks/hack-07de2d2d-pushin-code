## Если что-то горит

| Ситуация | Действие |
|---|---|
| Wi-Fi площадки лёг | телефон как точка доступа; деплой по ssh через него. Договориться заранее, чей телефон |
| OpenAI 429 / медленно | ретрай один раз в коде (уже в `agent_loop.py`); модель поменьше для извлечения; кэшировать ответы **вне главного пути** |
| бэк отстаёт критично | мастер **явно** отдаёт фронту кусок бэка по контракту и переназначает владение в `BOARD.md` |
| фронт отстаёт | бэк делает минимальную HTML-страницу на своём же сервере — сценарий должен быть виден |
| участник застрял > 20 мин | строка в «Застрял», мастер садится рядом на 10 минут, остальные не останавливаются |
| кейс дал данные, они грязные | `docs/references/data-quickstart.md`, режим B: чистое подмножество под сценарий, честно сказать в README |
| кейс требует того, чего нет в контракте | не переделывать контракт. Записать в README «Потенциал развития» |
| сервер деплоя недоступен | **не паниковать**: прод — преимущество, но не обязателен (п. 8.7). Чистый клон важнее. Записать в README, что прод временно недоступен, и дать инструкцию запуска |
| осталось 40 минут, сценарий не работает | freeze немедленно, откатить `main` на последний рабочий коммит, README и видео по нему |
