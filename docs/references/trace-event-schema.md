# Схема события следа решения — обязательная

Фронт рисует то, что пришло; мастер проверяет, что агент действует, а не отвечает.

```json
{"seq": 3, "ts": "2026-09-23T15:04:11+05:00",
 "type": "thought | tool_call | tool_result | action | verdict | error",
 "title": "Проверяю пересечения с активными нарядами",
 "body": "участок Н-3, окно 09:00–14:00",
 "meta": {"tool": "find_active_permits", "args": {}, "artifact": null}}
```

Эндпоинты по контракту: `POST /api/runs` → `{"id"}` · `GET /api/runs/{id}/events` — SSE, `data: <json>` · `GET /api/runs/{id}` → `{"done","artifact","events"}` · `GET /health` → `{"ok": true}`.

Четыре признака агента (все обязательны): инструменты, которые модель выбирает сама · запуск по событию · **действие с последствием** (`create_*`, `block_*`, `assign_*`) — событие `action` · след виден на экране. Лимит шагов — 8; упёрся → `error` и честный вердикт.
