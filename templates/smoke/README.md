# Дымовая заглушка

Минимальные `backend/` и `frontend/`, которые нужны ровно для одного: проверить, что
деплой, TLS и проксирование работают, **не дожидаясь продуктового кода**. Ни одной
зависимости сверх базовых образов.

Стек здесь ничего не диктует — исполнители берут что хотят. Единственный контракт,
который заглушка соблюдает и который должен соблюдать настоящий сервис:

- backend слушает `0.0.0.0:8000`, `GET /health` → `{"ok": true}`
- frontend слушает `0.0.0.0:3000`, зовёт API по относительному пути

## Как использовать

```bash
cp -r templates/smoke/backend templates/smoke/frontend .
docker compose -f infra/docker-compose.hosted.yml --env-file .env up -d --build
curl -fsS https://pushin.codes/health
```

Как только у Кубы и Сулы появятся настоящие сервисы — заменить содержимое `backend/`
и `frontend/`, compose и Caddy трогать не нужно.
