# Видео-демо — 90 секунд, запись экрана

Один дубль. Экран ведёт один человек, текст читает другой. Текст **написан до записи**.

| Сек | На экране | Текст (написать заранее) |
|---|---|---|
| 0–10 | титр: название + одна фраза | «<Проблема> — <цифра>. <Кто> тратит на это <сколько>.» |
| 10–25 | главный экран, пустое состояние | «<Название> — это <что>. <Роль> вводит <что>, агент <делает что>.» |
| 25–75 | **живой сквозной сценарий**: ввод → трейс агента появляется по шагам → **действие** → вердикт/артефакт | комментировать, что агент делает: «поднял правила… проверил историю… нашёл конфликт… сформировал документ» |
| 75–90 | титр: потенциал + команда | «Дальше: <шаг 1>, <шаг 2>. Команда <название>.» |

Кульминация — момент **действия** агента (секунда ~60). На нём пауза в тексте, пусть зритель увидит.

## Запись
- OBS или Loom, 1080p, окно браузера без лишних вкладок, шрифт увеличен.
- Мобильный вид не показывать — не хватит времени.
- Если голос не получился — субтитрами (см. ffmpeg ниже).

## Титры одной командой (без Remotion и прочего)

```bash
# титр в начале 3 сек (нужен шрифт с кириллицей, например DejaVuSans)
ffmpeg -f lavfi -i color=c=0x111111:s=1920x1080:d=3 -vf \
 "drawtext=fontfile=/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf:text='НАЗВАНИЕ':fontcolor=white:fontsize=96:x=(w-text_w)/2:y=(h-text_h)/2-60,\
  drawtext=fontfile=/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf:text='одна фраза о проекте':fontcolor=#cccccc:fontsize=40:x=(w-text_w)/2:y=(h-text_h)/2+60" \
 -r 30 title.mp4
# склейка: титр + запись
printf "file 'title.mp4'\nfile 'demo.mp4'\n" > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy final.mp4
```

Загрузка: YouTube «доступ по ссылке» или Loom. Открыть в инкогнито — проверить.
