# HackAlem AI — фундамент. Неизменен. Остальное — на усмотрение исполнителя

Один файл для Claude Code и Codex (`CLAUDE.md` → симлинк сюда). Стек, библиотеки, MCP, скилы — каждый свои; ограничений на реализацию нет. Есть семь правил.

1. **Контракт — закон.** `docs/CONTRACT.md`: сущности, API, экраны, один сквозной сценарий. Меняет только мастер; версия в шапке. Перед каждой задачей перечитай — версия могла смениться.
2. **Чекпоинт каждые 30 минут:** `scripts/checkpoint.sh "[T3] что сделано"`. Номер задачи из `BOARD.md` обязателен — по нему мастер сверяет пуш с планом. Без подтверждённого результата за любой отчётный час — дисквалификация (положение, п. 6.6).
3. **Проект должен подниматься из чистого клона** — это важнее любой второй фичи. `git clone` → `cp .env.example .env` → `docker compose up` → сценарий проходит. README и воспроизводимость дают **40 баллов из 100** на техотборе (п. 7.4), больше, чем любая фича. Развёрнутая версия — преимущество, но **не заменяет** запуск из репозитория (п. 8.7).
4. **Агент делает, а не отвечает — и без имитации.** Инструменты, которые модель выбирает сама; последний — действие (`create_*`, `block_*`, `assign_*`); след решения виден на экране по схеме `docs/references/trace-event-schema.md`. **Мок на главном пути запрещён:** самый дорогой критерий (техническая реализация, 25) прямо наказывает «ключевые функции, заменённые заранее подготовленными ответами или имитацией». Нужна заглушка — помечай её в README.
5. **Только этот репозиторий** (п. 6.8, 12.2 — разработка вне него = дисквалификация). Заготовки раскрыты в README (п. 6.4). Платформа закрывает репозиторий на запись сама по окончании окна, конкурсной версией считается содержимое на этот момент (п. 6.10) — последний push за 20 минут до конца, «докоммитим потом» не существует. Секреты — в `.env`; ключ OpenAI — из окружения, никогда в коде.
6. **Счёт — главная мерка.** `docs/SCORE.md` считает мастер по `docs/RUBRIC.md` (v2, редакция положения от 17.09). Цель — 100/100. Задачи в `BOARD.md` выводятся из разрывов счёта. Берёшь незанятую сверху, пишешь `@имя`. Появилась идея — строка в «Идеи», не код.
7. **Идентификаторы, коммиты, имена файлов — английский.** Тексты для жюри (README, интерфейс) — русский.

**Роли.** Абылай — мастер: контракт, доска, счёт, слияние, деплой, README, сдача; продуктовый код не пишет. Куба — backend по умолчанию. Сула — frontend по умолчанию. Умолчание переопределяется заявкой в доске.

**Документы.** `docs/hackathon/criteria.md` · `playbook.md` · `cases-forecast.md` · `regulation.md`. `docs/references/` — готовые куски по желанию; обязательна только схема событий.
