## Как выбирать файл по запросу

- `?version=latest` и `?version=2` → `forecasts_{D}.json`. `?version=1` на дне с v2 → `forecasts_{D}_v1.json`.
  Есть ли v1-файл, видно по `versions` в `issues.json` (или в самом выпуске): `[1, 2]` → есть.
  Дни с v2: **03.02, 08.02, 13.02, 19.02, 24.02, 27.02**.
- `turbine=plant|1|2` — в файлах всегда `all`: фильтруйте `rows` по полю `turbine` (`"1"`, `"2"`, `"plant"` — строки).
- SSE — массив событий в порядке `seq`. Проигрывайте с задержкой (разница `ts` или фиксированные 600 мс);
  последнее событие — `verdict`, после него поток закрывается.
- Ошибки `400`/`404` (`{"error": "…"}`) фикстурами не покрыты — проверьте руками.

## Что стоит знать

- **Этапы для панели агента** (`meta.stage`): у `run_model` вызов (`tool_call`) — `model`, результат — `forecast`;
  `publish_forecast` — `type: "action"`, `stage: null`; `thought` и `verdict` — `stage: null`, кроме решения
  «отказываюсь пересчитывать» в `run_events_new_weather_run.json` (`stage: "recalc"`, `status: "skip"`).
  Пересчёт не нужен — `recalc_forecast` с `status: "skip"`. `meta` всегда содержит все ключи:
  `tool, args, artifact, stage, status, issue_date, version, source` (`args`/`artifact` — из схемы событий).
- **Прогоны:** v1 — прогон D−1 00:00 UTC на всё окно; v2 — D 00:00 UTC для часов 1–24. Часы 25–48 у v1 и v2 совпадают
  (тот же прогон), поэтому пунктир расходится с линией только в первые сутки.
- **Где какие флаги:** 13.02 — демо-день (v2, спад −47 % за 2 ч + обледенение, как в сценарии §10);
  21.02 — `wind_gt20` и две рампы; 06.02, 19.02, 26.02 — `models_diverge` (коридор шире); 24.02 — три рампы;
  27.02 и 28.02 — обледенение; много дней без флагов. 09.02 — `check_data` со `status: "warn"` (пропуск температуры).
- **Live:** текущая v1 посчитана на прогоне 22.09 18:00 UTC, а последний вышедший — 23.09 00:00 UTC,
  так что «Проверить обновления погоды» есть что находить.
- **`metrics.period`** — `{"from", "to"}`: контракт форму не фиксирует; источник истины — `outputs/metrics_jan.json` от Кубы.

## Перегенерировать

```bash
python3 frontend/fixtures/_generate.py
```

Только стандартная библиотека, Python ≥ 3.9. Результат детерминирован: тот же код → те же байты.
Скрипт перезаписывает все `*.json` в этой папке и в конце проверяет каждый файл на форму §6 (ассерты).
