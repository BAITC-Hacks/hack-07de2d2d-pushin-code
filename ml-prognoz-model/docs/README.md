# Навигация по документации

`ml-prognoz-model` — автономный офлайн-эксперимент по прямому 48-часовому прогнозу мощности из двух исторических CSV. Это не backend-модуль и не реализация погодного контракта приложения версии 0.5 из корневого `docs/CONTRACT.md`: модель не запрашивает погоду, не предоставляет API и не вычисляет вероятностные интервалы P10/P90. Её результат — точечные прогнозы нормированной мощности.

## Результат и границы интерпретации

Общий победитель заранее объявленного сравнения — baseline **persistence** в `artifacts/csv_only/best_model.pkl`; он повторяет последнюю полную часовую мощность на все 48 горизонтов. Лучший обучаемый кандидат — **CatBoost** в `artifacts/csv_only/best_ml_model.pkl`. Он хранится отдельно и не был выбран вместо persistence из-за результатов holdout. Числа и причины такого решения смотрите в [results.md](results.md).

Предоставленные данные заканчиваются в январе 2026 года. Следовательно, невозможно честно выполнить полный ежедневный replay февраля или посчитать ошибку на всём феврале без новых наблюдений: для прогноза требуется недавняя история, а для оценки — будущая фактическая мощность.

## Команды

Выполняйте из корня `ml-prognoz-model`:

```bash
uv sync --extra dev
uv run wind-forecast --config configs/history.json prepare
uv run wind-forecast --config configs/history.json build-dataset
uv run wind-forecast --config configs/history.json plan
uv run wind-forecast --config configs/history.json train
uv run wind-forecast --config configs/history.json run
uv run wind-forecast --config configs/history.json predict \
  --model artifacts/csv_only/best_model.pkl \
  --origin 2026-01-31T19:00:00Z --hours 48
```

Конфигурация использует `../data/raw/turbine_1.csv` и `../data/raw/turbine_2.csv` относительно корня пакета. После клонирования обязательно сначала выполнить `prepare`, затем `build-dataset`; подготовленные Parquet не поставляются. В коммите есть исходный код, документация, отчёты и финальные артефакты, но нет исходных CSV, подготовленных таблиц, ZIP-архива и wheel.

`train` и `run` обучают модели. Остальные перечисленные команды не выполняют обучение. Старые `weather.md`, погодный кэш и pilot-материалы — legacy и не служат входом или доказательством итогового CSV-only результата.
