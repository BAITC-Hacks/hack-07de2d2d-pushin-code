# models — Куба

Обученные модели (`*.pkl`, до 20 МБ — в git). Для февраля — обучены на данных до 31.01.2026 включительно,
для бэктеста января — до 31.12.2025. Имя файла содержит границу обучения.

`quantile_2025-12-31.pkl` — фиксированная модель январского бэктеста; `quantile_2026-01-31.pkl` — модель
февральских выпусков. Признаки содержат только архивный прогноз ветра и температуры, а простои и пропуски
исключены из целевой метрики. Смещение SCADA выбирается по 1–7 января, 8–31 января остаются независимой
диагностикой. В live нет архивных лагов: его 48 часов относятся к тем же корзинам горизонта 1/2 суток, при
этом время получения прогноза сохраняется как ограничение доступности.
